Figma 团队导出隐私政策

更新于 2026 年 11 月 21 日 · 适用于 1.7.1 测试版

这款独立开发的 Chrome 扩展帮助你将有权保存的 Figma Design 源文件按团队归档到电脑。打开扩展时会读取当前 Figma 文件浏览器，勾选并开始导出后才会逐份处理原稿。

扩展会读取什么

为识别当前账号、显示可选范围和匹配下载，扩展读取 Figma 页面中的账号显示名和标识、团队和项目名称与标识、文件标题、文件链接、缩略图、可用的修改时间，以及当前文件的保存菜单、验证和图片准备状态。Chrome 会向扩展分发下载事件。扩展在本机筛选文件名，对候选的 .fig 核对来源和当前队列，不匹配的下载交回浏览器正常处理。Figma 编辑器中的脚本会临时记录本页生成的 Blob 地址以核对来源，标签页销毁时释放。Chrome 管理 Figma 登录会话，扩展没有读取 Cookie 或密码的权限。

数据去哪里

浏览器按正常网页流程与 Figma 通信。缩略图可能由 Figma 的图片域名（包括 figma.com 和 figmausercontent.com 子域）加载。可选的「读取团队目录」会把你主动填写的个人访问令牌通过 HTTPS 直接发给 api.figma.com，仅用于这次目录请求。令牌留在本次操作的内存中，扩展不会把它写进持久存储、清单或日志。

本地归档和校验会读取所选源文件字节、浏览器下载状态及所授权的文件夹。源文件写入你选择的团队目录。扩展没有开发者后端、统计 SDK、广告或云备份服务，也不会把文件上传给开发者。主动导出的 CSV 含文件名称、链接、路径、处理结果和时间，由你决定是否分享。

本机保存什么，如何清理

扩展在当前 Chrome 配置中保存团队目录索引、当前队列、文件标识、文件名、版本、下载记录标识、归档路径、大小、校验结果、时间、失败说明和历史批次，以便恢复和复核。已授权目录的句柄保存在本机 IndexedDB。在写入自选目录前，还会记录本次队列项、目标文件名、文件句柄和修改时间，以便中断后确认同一份文件。成功归档后清理这条写入记录。平时的勾选与界面状态暂存在标签页。开始导出后，扩展还会在本机保存本次准备的账号、范围、保存位置、已读目录的文件信息及进度，以便关闭工作台后恢复。建立队列或放弃读取后会清除此条准备记录。手动补档的确认记录包含所选本地文件名和大小。归档结果还会标明需要处理的接收副本。预览图在预览时读取，目录卡片的匹配标记可随队列保存。

默认下载直接写入团队目录。启用自动校验后，扩展在本机保存只读目录句柄和绑定路径。首次关联会下载一个仅含随机值的临时文本文件，核对实际位置后清理该文件及对应下载记录。后续使用本批下载记录中的准确文件名读取 .fig 并校验，不枚举其他下载内容。主动选择下载内的专用文件夹时，新批次在该文件夹内按团队保存。可以在「保存到」解除关联，或在 Chrome 中撤销目录访问权限。自选目录先接收至下载目录下的「Figma-导出接收」，最终副本核对成功后清理本次临时文件。中断或校验失败可能留下接收副本供你处理，可在批次明细中核对。卸载扩展会清除该扩展在此 Chrome 配置中的数据；已经落盘的设计稿、接收副本和 CSV 由你自行移除，Chrome 下载历史由浏览器管理。可在 Chrome 网站设置撤销目录权限，个人访问令牌可在 Figma 设置撤销。

有限使用与联系

上述数据仅用于本地批量导出、恢复和校验。我们遵守 Chrome 网上应用店用户数据政策的有限使用要求。我们不出售数据，不用它投放广告或评估信用，开发者无法从服务器查看你的设计稿。

本项目通过 GitHub Pages 提供公开隐私说明。打开公开网页时，GitHub 会出于安全目的记录访问者的 IP 地址。扩展内置的政策页面可离线查看。GitHub Pages 的数据处理说明

一般隐私问题可通过项目联系入口公开提出。涉及个人资料时，请通过 Chrome 网上应用店详情页的开发者联系方式私下联系。
